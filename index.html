About This App

This single-page application was built for COMP 3512 Assignment 2 using JavaScript, HTML, and CSS. It showcases client-side routing, JSON data handling, localStorage persistence, and dynamic DOM updates.

Data source: clothing-compact.json from provided files.

This uses Fetch API, localStorage, flex/grid-based layout, and simple component-style functions.
