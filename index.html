About Us

This single-page application was built for COMP 3512 Assignment 2 using vanilla JavaScript, HTML, and CSS. It demonstrates client-side routing, JSON data handling, localStorage persistence, and dynamic DOM updates.

Data source: clothing-compact.json (provided in the assignment).

Technologies: Fetch API, localStorage, flex/grid-based layout, and simple component-style functions inspired by the course labs.

Developer: Alaister Standen, Arbel Nachmias.
